# 小比的像素小屋 · XIAOBI'S LOFI ROOM

像素风 lofi 治愈互动小场景。摸遍小屋的每个角落，看小比发呆、蜷窝、打盹，伴以萨蒂 / 德彪西 / 肖邦的古典钢琴。

## 玩法

- **拖动小比**：在地毯 / 猫窝间挪动位置
- **双击小比**：在「发呆」与「睡觉」间切换动作
- **双击蘑菇灯**：开灯 / 关灯
- **双击窗户**：开关窗换换空气
- **点击挂画**：在《猫蒂丝》/ 花豹 / 埃及猫 / 空墙间轮换
- **拖动小鸟玩具**：放到地面、猫包、猫窝或窗台上；双击小鸟会摇晃
- **点击飘落的暖尘**：收集治愈值
- 右上角按钮：音乐开关 / 切歌 / 切换昼夜 / 操作提示

小屋会自动切换昼夜、开关窗户与蘑菇灯，小比也会自己换动作，静静陪着你。

## 技术

- 纯静态页面（HTML + CSS + 原生 JS），无构建依赖
- 角色立绘：`<video>` 逐帧绘制到 `<canvas>`，便于昼夜布光合成
- 房间背景：昼夜 × 窗户开关共四态，双层交叉淡入
- BGM：萨蒂《 Gymnopédie No.1 》、德彪西《月光》、肖邦《夜曲 Op.9 No.2》（公有领域录音），经 WebAudio 淡入淡出与切歌
- 像素粒子 / 飘字 / 对话框打字机均为 Canvas + DOM 实现

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署

直接托管任意静态服务器即可。仓库内含 `.nojekyll`，可直接用于 GitHub Pages。
